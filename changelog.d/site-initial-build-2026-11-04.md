### Added

- **The Bankai developer site (working codename: site).** A Gatsby 5 site for bankai.zheref.dev: hero with the positioning tagline and a CSS-only terminal of a real flow, the eight SDLC stages with their skills by code name plus alias, an interactive layers-and-gates diagram, per-surface quick start tabs, MDX docs (getting started, concepts, Hatsu guide, tiers and phases, Nen reference, handbooks, configuration, changelog), an open-source versus Cloud tier table, GitHub Sponsors, the ValleIA services section, an FAQ and the footer with both disclaimer lines verbatim. Every version, command, skill, agent, verb and changelog section is read from the pinned hatsu, nen and bankai-handbooks checkouts at build time by `scripts/sources/collect.mjs` into a local Gatsby source plugin; brand data lives in `src/brand/`; every URL, label, flag and price lives in `site.config.ts` with prices tagged TBD. The pricing page is built only behind `SHOW_PRICING=true`, never linked, never in the sitemap, served with noindex. Tests: Vitest (names-map completeness, codename redaction, config, components), a build lane that proves the pricing page absent in production and TBD-tagged in preview, Playwright smoke with axe at 390 px and 1440 px, and a Lighthouse script.
