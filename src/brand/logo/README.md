# Bankai brand assets (2026-11-04)

> **Draft, not for publication without Sergio's yes; pending lookalike/TM check.**

Locked system (Bankai · Logo Concepts → Build spec): Deterministic Path master mark; Nen = Loop & Gate; Hatsu = Gate Prompt; Handbooks, Library (coming later) and Cloud tier (name TBD) in the same system. No Akatsuki-AI mark. Wordmark: lowercase `bankai`, `ai` in the accent, same weight and case; never uppercase AI.

Naming: `<name>-<dark|light>[@2x|@4x].<svg|png>`. `dark` = artwork for dark backgrounds, `light` = for light backgrounds. SVGs have text converted to outlines and explicit width/height. PNGs at 1x/2x/4x, transparent.
