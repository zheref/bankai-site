Bankai is an open-source (MIT) AI-driven development lifecycle system: deterministic operations through a CLI (**Nen**), a governance harness inside the agent you already use (**Hatsu**), and per-stack handbooks as the canon (**Bankai-Handbooks**). Humans stay at explicit gates, G1 to G5, and every mechanical step is deterministic.

Everything on these pages that names a version, a command, a skill, an agent, a verb or a changelog entry is read from the repositories at build time.
