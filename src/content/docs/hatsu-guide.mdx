Hatsu is the governance harness: a plugin of skills and agents for Claude Code, Codex, Cursor and Antigravity. The names below are the ones the repository uses; the plain alias beside each is the site's reading (aliases marked in the names map as derived are open for review). The `shibari` → `musubi` rename is proposed only; `shibari` stays the code name until it is decided.

## v0.168.0 notes

The [published release notes](https://github.com/zheref/hatsu/releases/tag/v0.168.0) describe these changes beyond the catalogue summaries:

- The trusted-guard preflight accounts for every guard it derives, reports missing adapters alongside other results, and fails the PR test lane for an unhandled trusted guard.
- A catch-up that resolves a conflict of meaning reopens review of the merged head: applicable reviewers run a bounded delta pass before readiness is reported. A clean or mechanical catch-up carries the settled review forward.
- Declined cleanup rows are remembered and still offered. Matching rows from earlier sittings can be bundled by class for up to 30 days from their first decline; they are not silently discarded.
- `limbo` uses Nen's portable mirror form: it resolves the canon checkout and passes the repository's scenario explicitly to the mirror commands.

## The agents

Each independent has one discipline the lead delegates to rather than absorbing. All are advisory: none edits non-test source, votes, blocks or merges. The intake examiners challenge only at product intake and never review code.

## The skills

One directory each, invoked as `hatsu:<name>` in your surface's spelling. Each entry: what it does, what runs (as the skills and verbs it calls), who calls it, and the gate it stops at.

## Try a pull request on a device

`senkaimon` walks a consumer repository’s open pull requests one at a time. It shows the queue, asks for authorization to use the declared device and core checkout, then waits for your merge-or-revise decision tied to the tested head. It restores the parked checkout when the review ends and never merges a pull request itself.
