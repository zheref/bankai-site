Hatsu is the governance harness: a plugin of skills and agents for Claude Code, Codex, Cursor and Antigravity. The names below are the ones the repository uses; the plain alias beside each is the site's reading (aliases marked in the names map as derived are open for review). The `shibari` → `musubi` rename is proposed only; `shibari` stays the code name until it is decided.

## The agents

Each independent has one discipline the lead delegates to rather than absorbing. All are advisory: none edits non-test source, votes, blocks or merges. The intake examiners challenge only at product intake and never review code.

## The skills

One directory each, invoked as `hatsu:<name>` in your surface's spelling. Each entry: what it does, what runs (as the skills and verbs it calls), who calls it, and the gate it stops at.
